## 兩家店都說「1.67」，價差卻是一倍

「我上一副也是 1.67 啊，怎麼這副戴起來就順很多？」

這句話每個月都會在門市聽到幾次。也有反過來的：同樣寫著 1.67，新配的這副晚上開車看路燈，邊邊總覺得有一圈怪怪的顏色，眼睛往旁邊瞄的時候地板像會晃。度數沒改、折射率沒改，感受完全是兩回事。

問題出在一件很少被講清楚的事：**1.67 是材料規格，不是一片鏡片的完整身分證。**

它只回答一個問題：**同樣的度數，這片要做多厚。**其他一律沒管。你戴上去之後感受到的那些事，像是邊緣會不會晃、晚上會不會有彩色鑲邊、反光多不多、擦起來乾不乾淨，全部發生在折射率這個數字管不到的地方。

（還不熟折射率這個名詞，可以先看這篇打底：[鏡片「折射率」是什麼？1.60、1.67、1.74 差在哪](/blog/lens-refractive-index/)）

## 先把「1.67 管什麼、不管什麼」分清楚

用一句話記：**折射率是材料的折光能力，它只跟厚薄有關。**

| 這件事 | 折射率管嗎 |
|---|---|
| 同度數的鏡片厚不厚 | ✅ 直接決定 |
| 鏡片重不重 | ⚠️ 間接（薄了會輕一些，但也看材料比重） |
| 邊緣看東西會不會變形 | ❌ 看面型設計 |
| 夜間光源會不會有彩色鑲邊 | ❌ 看阿貝數 |
| 反光多不多、好不好擦 | ❌ 看鍍膜結構 |
| 戴在你臉上準不準 | ❌ 看鏡框與配戴參數 |

所以拿到兩張都寫著 1.67 的報價單，你知道的只有一件事：這兩片做出來的厚度大致同一個級距。剩下四件真的會影響體感的，報價單上那行字一個都沒告訴你。

下面就一件一件拆。

---

## 差異一｜阿貝數與色散：晚上開車才會現形的那圈彩邊

阿貝數反映的是鏡片的**色散**：白光被鏡片拆開之後，在明暗交界、路燈、招牌邊緣跑出來的那圈很淡的彩色鑲邊。阿貝數越高，色散越少、邊緣越乾淨。

折射率往上走，阿貝數多半會跟著往下掉，這是材料物理的取捨。不過它不是一路線性往下，中間會有起伏：**1.67 這個級距的樹脂鏡片，阿貝數概略落在 31–32 上下，1.74 反而回到 33 附近**（實際依各廠材料配方而異）。所以「越薄色散一定越嚴重」這句話並不成立。

重點來了：**同樣標示 1.67，各家用的單體配方不見得完全相同，阿貝數也就不會剛好是同一個數字。**差距通常不大，但落在對的人身上就會被放大：

- **深度數又常在晚上開車的人**：迎面的頭燈、路口號誌、逆光招牌，這些高反差光源正是色散最容易現形的場合。視線越偏離鏡片中心（像是轉頭看後照鏡），那圈彩邊越明顯。
- **白天在室內用眼為主的人**：老實說，這一項你多半感覺不到。

色散是真的存在的，只是它現形的場合很固定——高反差光源，加上視線偏離鏡片中心。你的一天裡如果幾乎沒有這兩件事同時發生的時候，這一項對你的意義就有限。

## 差異二｜面型設計：同樣 1.67，可以是四種完全不同的東西

這一項的差距，通常比材料本身大得多。

折射率講的是「材料」，面型設計講的是「這片鏡片的表面弧度怎麼算出來」。同樣一塊 1.67 的基材，可以被做成：

| 面型 | 差在哪 | 誰會有感 |
|---|---|---|
| **球面** | 弧度從中心到邊緣都一樣 | 度數一高，眼球往側邊轉就容易看到影像被拉扯 |
| **非球面** | 弧度從中心往邊緣漸變，修掉邊緣像差 | 現在多數鏡片的預設，鏡片也比較平 |
| **雙面非球面** | 前後兩面都漸變 | 度數高、鏡框大、常轉眼球看側邊的人 |
| **個人化自由曲面** | 把個人配戴參數（如配戴距離、傾斜角）算進去，再逐片運算刻製 | 對邊緣穩定度敏感、或戴多焦點的人 |

四片鏡片，報價單上可能都寫「1.67」，戴起來完全是四種東西。同一個品牌內部，1.67 會橫跨從入門到頂規好幾個系列，就是這個原因。**跨等級的落差，常常比跨品牌還明顯。**

（面型設計的原理拆解在這篇：[「非球面」鏡片是什麼？跟球面差在哪](/blog/aspheric-vs-spherical-lens/)）

**日常對照：**每天盯螢幕十小時的人，視線其實一直在鍵盤、螢幕、旁邊的第二螢幕之間橫向來回，用到的是鏡片中心以外那一大圈。邊緣穩不穩定，決定的不是「看不看得清楚」，而是**撐到下班的時候眼睛還舒不舒服**。反過來說，如果你一天大部分時間只是固定看一個方向，這筆設計費對你的意義就小很多。

## 差異三｜鍍膜結構：你每天實際在摸的那一面

基材決定厚薄，但你的手指、衣角、雨滴、路燈，接觸到的全都是鍍膜這一層。同樣的 1.67 基材配上不同的鍍膜結構，日常體感差很多：

- **抗反射鍍膜的層數與設計**：抗反射處理的作用是減少鏡片表面的反射光。反光少一點，晚上迎光時的干擾就少一點，別人看你的眼睛也比較不會被一片白光擋住。
- **防潑水、防油汙處理**：這一項最直接影響「好不好擦」。有做跟沒做，差在一張拭鏡布擦兩下就乾淨，還是越擦越花。
- **硬化膜**：樹脂原生材質偏軟，硬化膜是補這個先天弱點的。耐不耐刮很吃這一層。

各家原廠對鍍膜的命名、層數與處理方式都不同，實際規格請以原廠標示與說明文件為準；我們在門市能做的，是把你手上這副的鍍膜狀態拿出來，跟你要配的這副對照著看。

（鍍膜的完整原理另有一篇：[鏡片鍍膜完整解析](/blog/lens-coating-guide/)、[抗反射鍍膜的原理](/blog/anti-reflective-coating-principle/)）

騎車通勤的人對這段最有感：鍍膜的防潑水處理常常比多一個折射率級距還實用。雨天水珠是聚成一顆一顆滑掉，還是攤成一整片糊在你眼前，這件事每個雨天都會提醒你一次。

## 差異四｜鏡框與配戴參數：再好的鏡片也逃不掉這一關

最後這一項，決定前面三項是全部發揮還是全部歸零。

同一片 1.67，裝在兩支不同的鏡框上，會是兩個結果：

- **光學中心有沒有對準你的瞳孔**：沒對準，視線等於天天從鏡片邊緣穿過去，眼睛得多花力氣代償。你花錢買的非球面設計，就是在這一步被浪費掉的。
- **鏡片離眼睛多遠（頂點距離）**：這段幾毫米的空隙會左右你實際感受到的度數，度數越高越明顯。
- **鏡框大小**：框越大，鏡片直徑越大，邊緣越厚、重量越重。有時候把框改小一號，比升一個折射率級距還有效。
- **鏡框有沒有戴穩戴正**：一直往下滑、一邊高一邊低，前面量得再準都要打折。

所以有句話我們每次都會講：**升級鏡片規格之前，先確認前面這幾件有沒有做對。**順序反了，錢花下去，很容易買不到你以為會有的那個改善。

（同樣的道理，換成度數版本講過一次：[度數一樣，為什麼兩副眼鏡戴起來差這麼多](/blog/same-prescription-different-feel/)、[「頂點距離」是什麼？為什麼高度數眼鏡要算它](/blog/vertex-distance/)）

## 品牌有沒有差？有，但不在那個數字上

品牌之間的差異，集中在**面型設計的演算法、個人化參數的納入方式、鍍膜的製程規格**這幾件事，不在 1.67 那個數字上。所以「哪個品牌比較好」多半是問錯方向，換個問法比較有用：**這個等級的設計，配不配得上我每天用眼的方式。**

以規格清單來說明會更具體。本店經銷品牌中，1.67 這個折射率同時出現在多個不同等級的系列裡：

- **蔡司 ZEISS**（簽約認證經銷）：單光的清銳（FSV / SV ClearView）為 1.56 / 1.60 / 1.67 / 1.74；頂級型個人化（SV Individual）為 1.50 / 1.60 / 1.67 / 1.74。
- **HOYA**（經銷）：單焦的非球面 / 球面（Nulux Classic / Hilux）為 1.50 / 1.55 / 1.60 / 1.67 / 1.74；個人化 / 雙面非球面（Nulux V+ / EP）為 1.60 / 1.67 / 1.74。

同一個 1.67，在同一個品牌裡就橫跨了入門到個人化好幾個位置。下次看到報價單上那行 1.67，該追問的不是「這是哪一牌」，是「**哪一個系列、哪一個等級**」。完整品名與折射率規格都列在[能見度鏡片專區](/lenses/)，品牌之間怎麼比較的原則整理在[鏡片品牌怎麼選](/guide/lens-brands/)。

## 所以，你該怎麼看那張報價單

給你一個現場就能用的順序：

1. **先問等級，不是先問品牌。**「這是哪個系列？球面、非球面還是個人化？」
2. **再問鍍膜做了什麼。**抗反射、防潑水防油汙、硬化膜，各有沒有。
3. **最後才比折射率。**確認你的度數與鏡框尺寸，真的需要走到 1.67 嗎？（度數不深的話，1.60 可能就夠了）
4. **把鏡框一起算進去。**框型、大小、能不能戴穩，跟鏡片規格同等重要。

## 花下去也未必有感的那一段

前面拆了四項差異，但有一句話得說清楚：**有些差異，你是真的感覺不到的。**

低度數、白天室內用眼為主、不太開夜車的人，從標準非球面升到個人化設計，體感的落差可能小到不值得那筆錢。我們也遇過換了更高等級鏡片還是不舒服的個案，最後查出來問題在散光軸向或鏡框變形，跟鏡片一點關係都沒有，那種情況換再貴的片也是白換。

會不會有花了錢還是不滿意的？會。這種話先講，比事後解釋誠實。

## 常見問題

**Q：同樣 1.67，為什麼價差可以到一倍以上？**

因為 1.67 只標示了材料的折射率，也就是同度數下鏡片做出來多厚，它沒有標示面型設計、鍍膜規格與是否納入個人化參數。同一個 1.67 可以是球面、非球面、雙面非球面或個人化自由曲面，這幾種的設計與加工成本本來就不同級距；鍍膜的層數與防潑水防油汙處理也各有差異。所以看到價差時，該問的是系列與等級，而不是折射率。實際適不適合你，建議由驗光人員看過你的度數、鏡框與用眼習慣後再判斷。

**Q：1.67 的鏡片是不是一定比 1.60 好？**

不是。折射率只決定同度數下的厚薄，數字高不代表看得比較清楚。而且折射率往上走，阿貝數多半會往下掉，也就是夜間高反差光源下的色散可能反而多一點。度數不深的人選 1.67，換來的厚薄差異其實有限。折射率是「度數越深越有感」的規格，值不值得，要放進你的度數、鏡框大小與外觀在意程度一起算。

**Q：晚上開車看路燈有一圈彩色的邊，是鏡片有問題嗎？**

那多半是色散，跟阿貝數有關，不一定是鏡片瑕疵。高折射率材料的阿貝數較低，色散相對明顯，而且視線越偏離鏡片光學中心（例如轉頭看後照鏡）越容易被察覺。不過在下結論之前，有幾件事要先排除：光學中心有沒有對準瞳孔、鏡框有沒有變形或下滑、抗反射鍍膜的狀況如何。這幾件都會影響夜間的視覺舒適度，驗光人員實際量過才分得出是哪一段造成的，眼鏡帶著一起來會快很多。

**Q：換品牌會不會比較好？**

不一定，要看你換的是「品牌」還是「等級」。同一個品牌裡，入門系列跟個人化系列的落差，常常比兩個品牌的同等級之間更大。真正決定體感的順序是：驗光精準度 → 配鏡參數 → 鏡框調整 → 鏡片設計與材質。前三項沒到位就換品牌，通常換不出你要的結果。

**Q：我要怎麼知道自己現在戴的是哪一種 1.67？**

把你的配鏡單據或鏡片保證書帶著，上面通常會註記系列名稱與鍍膜項目。如果單據已經找不到了，帶著眼鏡到門市，驗光人員可以用鏡片鑑別的方式協助判讀基本資訊，再對照你實際的用眼狀況，看看下一副該調整哪一段。

## 折射率是規格，適不適合是另一回事

「1.67」是一個把很多資訊壓縮掉的數字。它老實告訴你這片有多薄，其他的一句都不說。

你每天在感受的，剛好都落在它沒說的那一區：邊緣穩不穩、夜裡的燈乾不乾淨、雨天好不好擦、鏡框有沒有把光學中心對在該在的位置。這些不會寫在報價單的第一行，卻是你三年後回頭評價這副眼鏡的依據。

如果你手上有一副「規格看起來沒問題、戴起來就是差一點」的眼鏡，最快的做法是把它帶來，跟你要配的新的擺在一起，一項一項對。預約視覺諮詢，由驗光人員看過你的度數、鏡框，還有你每天真正在看的東西，再說明差別在哪一段。
