## 頂規多焦點鏡片，不是每個人都需要

這篇不是業配。能見度視覺中心是蔡司簽約經銷商，但我更希望你花對錢。

多焦點鏡片同一個品牌就分好幾個等級：標準款、數位優化款，最上面是依你個人參數訂製的頂規款。以蔡司為例，頂規的個人化系列叫 Individual²；其他品牌也有各自的個人化設計。等級越高，價格越高，值不值得，要看你的眼睛和用眼習慣。

## 頂規和一般多焦點鏡片，差在哪裡？

### 一般多焦點：照平均值設計

標準等級的多焦點鏡片，光學設計是用**統計上的平均值**做出來的：平均的臉型、平均的鏡框角度、平均的眼睛位置。配鏡時依你的度數加工，大部分人戴起來沒有問題。

問題是你的臉不一定是平均值。鏡框戴上去的角度、鏡片離眼睛的距離，只要跟平均值差得多，鏡片設計就沒辦法完全照顧到。

### 頂規多焦點：照你的臉和鏡框重新計算

個人化訂製款會把以下參數交給鏡片廠，重新計算鏡片每一個區域的光學設計：

| 參數 | 量的是什麼 |
|------|------|
| 單眼瞳距 | 左右眼各自到鼻樑中心的距離 |
| 瞳高 | 瞳孔在鏡框裡的高度 |
| **頂點距離** | 鏡片後表面到眼睛的距離 |
| **前傾角** | 鏡框往臉頰方向傾斜的角度 |
| **面彎角** | 鏡框順著臉型彎的弧度 |
| 閱讀距離 | 你平常看近的習慣距離 |

這些數字都要在你選好鏡框、實際戴上之後才量得準，所以頂規多焦點的價差，有一部分是買這段量測。

## 訂製款怎麼配：多量的那幾步

1. 完整的臨床驗光（45～60 分鐘）
2. 先選定鏡框，再戴著鏡框量頂點距離、前傾角、面彎角與瞳高
3. 參數送鏡片廠訂製
4. 取件時戴上確認，現場調整鏡架
5. 取件後約 2 週回店追蹤一次

## 哪些人換頂規多焦點，感受最明顯？

### 感受比較明顯的人

- **度數深的人**：度數越深，鏡片離眼睛的距離差一點，實際感受到的度數就差越多
- **散光度數高、或散光角度是斜的人**：鏡框的傾斜角度會影響散光的矯正效果，參數量得越準，越不容易覺得「怪怪的」
- **一天要在很多距離之間切換的人**：電腦、文件、手機、會議室來回看，看近和看中距離的區域照自己的距離設計，比較順
- **之前戴標準款多焦點一直適應不良的人**：先查是不是量測或鏡架調整出了問題，再評估要不要升級

### 差異不明顯、可以省下來的人

- 度數不深、沒有散光
- 鏡框選的是平面、小框的款式，傾斜角和弧度本來就小
- 用眼距離單純，不常在遠、中、近之間切換

這類條件，把預算放在一次完整的驗光和鏡框調整，體感反而更明顯。

## 頂規多焦點鏡片常見問題

### Q：頂規多焦點和一般多焦點價差多大？
A：價差主要來自設計等級，實際金額依度數、折射率與鍍膜而定，驗光完、選好鏡框之後才能給準確的報價。

### Q：配了頂規多焦點，戴不習慣怎麼辦？
A：在能見度配的眼鏡，取件後的鏡架調整不另外收費；戴一段時間仍不習慣，回店由驗光人員重新檢查度數與配戴狀況。若確認是鏡片本身的問題，依原廠保固處理。

### Q：一定要配同品牌的鏡框嗎？
A：不需要。個人化鏡片可以配在大多數鏡框上，但前傾角和面彎角要在選定鏡框之後才能量，所以要先挑框、再訂片。
